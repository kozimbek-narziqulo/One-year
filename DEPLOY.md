# Как выложить бесплатно и поставить на iPhone

Нужно: аккаунт GitHub и аккаунт Vercel (оба бесплатные; Vercel Hobby рассчитан на личное использование), iPhone с Safari.

## 1. Положить проект на GitHub (5 минут)
1. Распакуйте архив `garden-journal.zip` на компьютере.
2. Зайдите на github.com, войдите (или зарегистрируйтесь), нажмите «+» → **New repository**.
3. Имя, например, `garden-journal`. Оставьте **Private** (приватный), нажмите **Create repository**.
4. На странице нового репозитория нажмите ссылку **uploading an existing file**.
5. Откройте распакованную папку и перетащите **её содержимое** (папки `app`, `components`, `lib`, файлы `package.json` и остальные), не саму папку и не zip. Нажмите **Commit changes**.

## 2. Подключить Vercel (3 минуты)
1. Зайдите на vercel.com → **Sign Up** → **Continue with GitHub**.
2. **Add New… → Project**, найдите `garden-journal`, нажмите **Import**.
3. Ничего не меняйте: Vercel сам определит Next.js. Нажмите **Deploy**.
4. Через 1–2 минуты появится ссылка вида `https://garden-journal-xxxx.vercel.app`. Это ваш сайт.

Если сборка упала (красная надпись Error): откройте вкладку **Logs**, скопируйте последние 30 строк и пришлите мне, я исправлю. Я не мог запустить настоящую сборку Next.js в своей среде.

## 3. Установить на iPhone
1. Откройте ссылку **в Safari** (не в Chrome и не из мессенджера).
2. Подождите несколько секунд, пока страница полностью загрузится (так включается работа без сети).
3. Нажмите «Поделиться» (квадрат со стрелкой) → прокрутите вниз → **На экран «Домой»** → **Добавить**.
4. Запускайте приложение с нового значка. Для проверки офлайна: включите авиарежим и откройте значок ещё раз.

## Важно про данные
- Записи хранятся только на телефоне. Раз в месяц делайте копию: значок ⚙ → «Сохранить копию».
- Записи, сделанные в Safari до установки, **не переходят** в установленное приложение: у них отдельное хранилище. Сначала сохраните копию в Safari, потом в установленном приложении «Выбрать файл копии».
- Новая версия приложения подтягивается сама при следующем открытии с интернетом. Записи при этом не трогаются.
